# Color Palette and Brand Style

Use this palette as the single source for diagram colors. Colors encode meaning; pair a dark stroke with a lighter fill.

## Shape colors

| Purpose              | Fill      | Stroke                    |
| -------------------- | --------- | ------------------------- |
| Primary or neutral   | `#3b82f6` | `#1e3a5f`                 |
| Secondary            | `#60a5fa` | `#1e3a5f`                 |
| Tertiary             | `#93c5fd` | `#1e3a5f`                 |
| Start or trigger     | `#fed7aa` | `#c2410c`                 |
| End or success       | `#a7f3d0` | `#047857`                 |
| Warning or reset     | `#fee2e2` | `#dc2626`                 |
| Decision             | `#fef3c7` | `#b45309`                 |
| AI or LLM            | `#ddd6fe` | `#6d28d9`                 |
| Inactive or disabled | `#dbeafe` | `#1e40af` (dashed stroke) |
| Error                | `#fecaca` | `#b91c1c`                 |

## Text colors

| Level               | Color     | Use                               |
| ------------------- | --------- | --------------------------------- |
| Title               | `#1e40af` | Section headings and major labels |
| Subtitle            | `#3b82f6` | Subheadings and secondary labels  |
| Body or detail      | `#64748b` | Descriptions and annotations      |
| Text on light fills | `#374151` | Shape labels                      |
| Text on dark fills  | `#ffffff` | Shape labels                      |

## Evidence artifacts and lines

- Code and data examples use `#1e293b` backgrounds. JSON example text uses `#22c55e`.
- Arrows use the stroke color of their source concept.
- Structural lines use `#1e3a5f` or `#64748b`.
- Marker dots use `#3b82f6` for both fill and stroke.
- Use a white (`#ffffff`) canvas background.
